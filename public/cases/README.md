# Prints dos projetos

Coloque aqui os screenshots reais de cada projeto. Os nomes de arquivo abaixo
são os que o site espera (referenciados em `src/data/content.ts`):

| Arquivo                          | Projeto                                   |
| -------------------------------- | ----------------------------------------- |
| `historias-para-a-vida.png`      | Histórias para a Vida (site do livro)     |
| `missao-santa-faustina.png`      | Missão Santa Faustina (site institucional)|
| `financemate.png`                | FinanceMate (controle financeiro)         |
| `devburger.png`                  | DevBurger (loja online + API REST)        |

Sugestão: capturas em ~1200×750 px (proporção parecida com o card, que é ~16:10),
formato PNG ou JPG. Enquanto os arquivos não existirem, o card mostra só o texto
sobre um fundo escuro (a imagem some sozinha via `onError`).
